# Updream 插件 UI 诊断与重制说明

## 一、原 UI 的实测问题

以下每一条都是在真实渲染（真组件 + 真 CSS，深色/浅色两套主题变量）下量出来的，不是观感推测。

### 1. 样式表是从另一个插件整段抄的，几乎全是死代码

| 指标 | 数值 |
| --- | --- |
| CSS 体积 | 146,049 字节 / 2,052 行 / 556 条规则 |
| 定义的选择器 | 372 个 |
| JS 实际用到的类 | 80 个 |
| **从未被引用的类** | **293 个（79%）** |

`dcu-pool-modebar`、`dcu-device-dialog`、`dcu-cli-bridge-*`、`dcu-oauth-url`、
`dcu-sdk-dir-row`……这些类在这个插件里根本不存在对应组件，全部是从
`dsh-connect-workbuddy` 连皮一起搬过来的。还有 19 个选择器在同一张表里重复定义
（`.dcu-pool-select` 出现 3 次、`.dcu-pool-row` 2 次）。

### 2. 引用了 16 个主题里根本不存在的变量

DSH 运行时注册的主题 token 只有 16 个，而这张表引用了 28 个。不存在的 12 个
全部带硬编码深色兜底，于是**浅色主题下这些地方仍然是深色**：

```
--dsw-alias-bg-layer-3   ×21 次   （不是真 token）
--dsw-alias-label-dimmed ×16 次
--dsw-alias-interactive-bg-hover ×6 次
--dsw-alias-bg-l1 / label-error / label-caution / bg-mask-1 / elevation-prominent …
```

另有 11 处 `var()` **连兜底值都没有**（`.dcu-btn-primary`、`.dcu-btn-outline`、
`.dcu-composer-panel` 等），变量缺失时整条声明直接失效。

### 3. 账号表结构错位，信息落在错误的列里

表头是「账号 / 当前 / 剩余积分」三列，但行里塞了 5 个格子（其中 `probe`、
`checkin` 两个是空的遗留单元格）。实际渲染出来：

```
账号                              当前        剩余积分
账号甲                            [当前]      [读余额]
demo-user · sk-DEMO…XXXX          [切换][移除]
```

- 「当前」徽章跑到中间列，和右侧的「读余额」并排，看起来像两个并列操作；
- 余额位置的按钮叫「读余额」，但表头写的是「剩余积分」——同一列两种语义；
- 第二个账号的余额没有自动读取，必须逐个手点「读余额」。

### 4. 表头左上角有一个绿字「当前」压在「账号」上面

`.dcu-pool-row-head` 与 `.dcu-pool-row-current` 同时命中同一个网格，
`grid-area` 冲突导致徽章溢出到表头行外，和列标题叠字。

### 5. 主按钮在浅色主题下等于不可见

```css
.dcu-btn-primary{background:var(--dsw-alias-label-primary);color:var(--dsw-alias-bg-layer-3)}
```

`--dsw-alias-label-primary` 在深色主题是近白色，`--dsw-alias-bg-layer-3`
**根本不存在** → 文字色落空 → 浅色背景上的浅色文字。截图里「保存」就是一个
看不清的灰块。这不是审美问题，是可用性缺陷。

### 6. 页签栏没有层级

四个页签是 `flex:1` 的裸文字按钮，`padding:0`，除了「选中变亮一点」没有任何
选中指示物。截图里它们就是横排四段灰字，和正文抢同一条视觉基线。

### 7. 整页没有标题区、没有分组、没有留白节奏

从页签直接掉进表单块，所有内容同色同框，读者无法区分「这是账号」「这是模型」
「这是开关」。每个块的间距、圆角、边框都来自别的插件的视觉语言。

---

## 二、重制方案

### 设计语言

- **只用真 token**：16 个已注册主题变量，零硬编码颜色；浅色/深色自动跟随。
- **一套自己的骨架**：`dcu-page / dcu-card / dcu-row / dcu-tabbar / dcu-switch /
  dcu-btn / dcu-badge`，全部被引用，零死代码。
- **三层表面**：页面底色（bg-base）→ 卡片（bg-layer-1）→ 行内凹槽（bg-layer-2）。
  层级靠底色深浅 + 1px border-l1 表达，不靠阴影。
- **品牌色只做三件事**：选中态、主按钮、当前账号。

### 结构调整

| 区域 | 原来 | 现在 |
| --- | --- | --- |
| 页头 | 无 | 图标 + 标题 + 一句话说明 |
| 页签 | 裸文字横排 | 下划线式 segmented tab，选中态 2px 品牌色 |
| 账号 | 5 列错位网格 | 卡片行：头像圆点 + 名称/Key + 余额（自动读取）+ 操作 |
| 模型 | 混在 pool-table 里 | 独立卡片，每个类型一组，行内复选框 + 档位徽章 |
| 开关 | 6 行 | 分组卡片，标题 + 说明 + 右侧开关 |
| 保存栏 | 底部普通行 | 吸底，状态 + 放弃/保存（品牌色实心） |
| 积分读数 | 248px 弹层 | 260px 弹层，账号行整行可点，余额右对齐 |

### 行为不变

所有 Host 路由、`ROUTE.*` 调用、状态机、locale key、注册的 slot 名称与 id
全部保持原样。这次只重做呈现层。
